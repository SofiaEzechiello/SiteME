# Marques Ezechiello Advogados Associados

Website institucional do **Marques Ezechiello Advogados Associados**, desenvolvido em React com foco em uma experiência moderna, responsiva e alinhada à identidade visual do escritório.

**Site:** https://marquesezechiello.com.br

---

## Sobre o projeto

O projeto foi desenvolvido para substituir a versão anterior do site institucional do escritório, trazendo uma estrutura mais moderna, organizada e escalável.

O site apresenta:

- Página inicial institucional
- História do escritório
- Equipe e perfis profissionais
- Áreas de atuação
- Página específica de Direito Trabalhista
- Página específica de Direito Previdenciário
- Página específica de Direito Cível
- Página específica de Direito Empresarial
- Seção de diferenciais
- Depoimentos
- Informações de contato
- Navegação responsiva para desktop e dispositivos móveis

---

## Áreas de atuação

O site apresenta conteúdos específicos para as principais áreas de atuação do escritório:

- Direito Trabalhista
- Direito Previdenciário
- Direito Cível
- Direito Empresarial

O escritório possui especial experiência em demandas trabalhistas, inclusive envolvendo profissionais da área hospitalar e da saúde, além de atuação empresarial em habilitação e acompanhamento de créditos em processos de recuperação judicial.
